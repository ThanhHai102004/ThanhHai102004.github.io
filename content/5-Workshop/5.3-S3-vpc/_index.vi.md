Trước khi triển khai hệ thống, tôi đã chuẩn bị mã nguồn frontend, tài khoản AWS, kho lưu trữ GitHub và các quyền cần thiết để tạo các tài nguyên trên AWS.

### Các thành phần cần có

- Mã nguồn của Campus IT Support Ticket Portal.
- Kho lưu trữ GitHub được kết nối với AWS Amplify Hosting.
- Tài khoản AWS để tạo các tài nguyên như Amplify, Cognito, API Gateway, Lambda, DynamoDB, S3, SES, CloudWatch và IAM.
- Một vùng AWS thống nhất cho các dịch vụ backend.
- Địa chỉ email dùng để kiểm tra các thông báo qua Amazon SES.

### Kết quả

Sau bước chuẩn bị này, dự án đã sẵn sàng cho việc triển khai frontend và cấu hình backend serverless.
