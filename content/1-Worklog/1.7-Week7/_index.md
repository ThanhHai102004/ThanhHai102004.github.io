### Week 7 Objectives (01/06/2026 – 07/06/2026)
- Deploy a static website on Amazon S3.
- Improve access speed using Amazon CloudFront.
- Test the accessibility and reliability of the website.
- Optimize storage and content delivery configuration.
- Prepare the environment for the group project.
- Record the deployment results.

### Activities Completed
In the seventh week, I focused on implementing a static website using Amazon S3 and Amazon CloudFront. I learned that S3 is suitable for hosting static content such as HTML, CSS, and image files, while CloudFront can improve access speed by distributing content through edge locations. This combination is a practical and efficient approach for deploying websites in the cloud.

I also tested the website’s accessibility from different perspectives to ensure that the content could be opened properly and that the deployment was functioning as expected. During the process, I considered how to optimize storage settings and content delivery configuration to improve performance and reduce unnecessary resource usage. In addition, I prepared the environment so that the group could continue using the deployed setup for project-related purposes.

### Results Achieved
- Successfully deployed a static website on Amazon S3.
- Improved content delivery performance using Amazon CloudFront.
- Verified that the website could be accessed properly.
- Gained practical experience in optimizing storage and distribution settings.
- Prepared a more suitable environment for the team project.

### Reflection
Week 7 gave me a practical view of how static websites are deployed and delivered on AWS. The experience showed that a well-configured storage and distribution setup can improve both performance and usability for end users.
