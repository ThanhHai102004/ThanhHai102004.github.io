### Week 2 Objectives (27/04/2026 – 03/05/2026)
- Deepen understanding of AWS core services and their use cases.
- Practice using the AWS Console and CLI more confidently.
- Continue exploring virtualization and storage concepts through EC2 and EBS.

### Activities Completed
In the second week, I continued to expand my knowledge of the AWS platform by focusing on the practical use of core services. I spent time reviewing the main service categories such as Compute, Storage, Networking, and Database, and connecting them to real cloud scenarios. This helped me better understand how different AWS services work together in a complete cloud environment.

I also continued practicing with the AWS Console and CLI by checking account configuration, listing available regions, and exploring virtual machine-related services such as EC2. This helped me become more comfortable using the management tools that are essential for working with AWS resources in a professional environment.

During this week, I studied EC2 in more detail, including instance types, AMIs, storage options, and how to connect to instances through SSH. I also reinforced my understanding of how EBS volumes support persistent storage for EC2 instances.

### Results Achieved
- Strengthened knowledge of AWS core services and their roles.
- Became more familiar with the AWS Console and command-line operations.
- Practiced basic AWS CLI tasks such as checking configuration and exploring services.
- Improved understanding of EC2 and EBS fundamentals.
- Built confidence in using the platform for basic cloud administration tasks.

### Reflection
Week 2 helped me move from basic awareness to more practical understanding. I realized that the true value of AWS lies not only in knowing the service names, but also in understanding how to manage them effectively through both the console and CLI.
