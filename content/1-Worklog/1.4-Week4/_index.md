### Week 4 Objectives (11/05/2026 – 17/05/2026)
- Learn the fundamentals of AWS Lambda.
- Understand how Amazon API Gateway integrates with serverless applications.
- Practice building a simple API-based workflow in AWS.

### Activities Completed
In the fourth week, I studied serverless computing with AWS Lambda and Amazon API Gateway. I learned that Lambda allows functions to run without managing servers, while API Gateway provides a way to expose those functions through HTTP endpoints. This combination is widely used to build lightweight and scalable applications.

I also explored how Lambda functions are triggered, how they connect with API requests, and how basic permissions are configured through IAM roles. By practicing a simple example, I gained a better understanding of how serverless services work together in real-world cloud applications.

### Results Achieved
- Gained a clear understanding of AWS Lambda.
- Learned how Amazon API Gateway exposes Lambda functions through APIs.
- Understood the role of serverless architecture in modern cloud development.
- Built initial practical knowledge of integrating services in AWS.

### Reflection
Week 4 helped me understand the value of serverless computing. Lambda and API Gateway make it possible to build applications faster while reducing the burden of infrastructure management.
