### Mục tiêu tuần 4 (11/05/2026 – 17/05/2026)
- Tìm hiểu nền tảng về AWS Lambda.
- Hiểu cách Amazon API Gateway tích hợp với các ứng dụng serverless.
- Thực hành xây dựng một quy trình API đơn giản trên AWS.

### Các hoạt động đã thực hiện
Trong tuần thứ tư, em nghiên cứu về điện toán serverless với AWS Lambda và Amazon API Gateway. Em hiểu rằng Lambda cho phép các hàm chạy mà không cần quản lý máy chủ, trong khi API Gateway cung cấp cách để expose các hàm đó thông qua các endpoint HTTP. Đây là một mô hình thường được sử dụng để xây dựng các ứng dụng nhẹ và có khả năng mở rộng tốt.

Em cũng tìm hiểu cách các hàm Lambda được kích hoạt, cách chúng kết nối với các request API và cách thiết lập quyền truy cập cơ bản thông qua IAM role. Qua việc thực hành một ví dụ đơn giản, em có cái nhìn rõ hơn về cách các dịch vụ serverless phối hợp với nhau trong các ứng dụng cloud thực tế.

### Kết quả đạt được
- Hiểu rõ hơn về AWS Lambda.
- Nắm được cách Amazon API Gateway mở các hàm Lambda thành API.
- Hiểu được vai trò của kiến trúc serverless trong phát triển cloud hiện đại.
- Có kiến thức thực tế ban đầu về cách tích hợp các dịch vụ trên AWS.

### Nhận xét
Tuần 4 giúp em hiểu thêm về giá trị của serverless computing. Lambda và API Gateway cho phép xây dựng ứng dụng nhanh hơn và giảm bớt gánh nặng quản trị hạ tầng.
